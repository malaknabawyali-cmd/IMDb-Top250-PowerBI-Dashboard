🎬 IMDb Top 250 — Power BI Analytics Dashboard
PROJECT OVERVIEW
An interactive Power BI dashboard exploring the 250 highest-rated movies on IMDb. The project focuses on audience engagement, genre distribution, and release trends across decades.
Dashboard preview: Dashboard.png
KEY INSIGHTS
• Movies analyzed: 250
• Total votes: 409M+
• Top represented genres: Drama, Action, and Crime
• Release trends: The dataset shows a notable concentration of top-rated movies released between 1990 and 2010.
TOOLS AND DATA
• Power BI: Data visualization, dashboard design, and interactive filtering
• Dataset: IMDb Top 250 movies
